# Zappush for Cursor

Connect Cursor to your Zappush workspace. Ask about a store's analytics and audiences, set up a store's tracking and delivery, and work with your lead pipeline and lead conversions.

## Install

Install Zappush from the Cursor Marketplace. The first time Cursor starts the server, a browser opens for you to sign in to Zappush. Node.js is required, because the server runs with `npx @zappush/mcp`.

## What you can do

- Query a store's events, orders and attribution.
- List audiences and see which audiences a shopper belongs to.
- Set up a store: compliant page, Meta pixel and routes.
- Find and move leads in your pipeline, with a preview and an undo.
- Create and change lead conversions that send events to Meta, Google and other destinations.

Changes always show a preview first and apply only after you agree. A connection with read access can only read.
